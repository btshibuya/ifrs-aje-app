## 補足

- **計算**
  - 17論点すべて、取込 → 明細チェック → 計算 → 確定までアプリで行います。仕訳の1行から、計算シート・明細・元資料（原本とハッシュ値）までたどれます。
  - 「ファイル取込」は会計ソフト等のファイル（または手入力）を、「収集パッケージ」は子会社が提出した様式の入力を、明細として取り込みます。
- **方式**
  - 累積は当期の変動分を、洗替は期末の全額を出します。
  - 連結精算表の開始仕訳・開始実現仕訳の作り方は、この方式で変わります。
- **方針（適用の有無）**：会社ごとに異なります。
  - 7 のれん・10 株式報酬は、もともと全社「対象外」です。
  - 11 償却原価は、もともと全社「重要性なし」です。
  - テストデータでは、7 は S02・S05・S08、10 は S03・S09、11 は S04・S06・S10 だけ「適用」にしています。
  - 2 は S07、1 は S05、3 は S09 が対象外または重要性なしです。
- **外した論点**：リース（IFRS 16）と表示の組替えは外しています。
- **詳しい内容**：各論点の基準の概要と日本基準との違いは、アプリのメニュー「論点の解説」で見られます。
